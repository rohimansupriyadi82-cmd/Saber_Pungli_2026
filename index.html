Spanduk (Web) Output akan sama persis selama file gambar sumbernya sama
Jika gambar tidak muncul: klik Pilih Gambar atau drag & drop file gambar ke area ini. Alternatif: simpan file bernama spanduk.png di folder yang sama dengan index.html.
